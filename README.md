# KhmerXScore — Complete Experiment Suite

**Explainable AI for Automated Scoring of Khmer Short-Answer Questions**

## Architecture

- **KX-CL**: XLM-R dual-encoder + 4-way interaction `[e_A; e_R; e_A-e_R; e_A⊙e_R]` + CORN ordinal regression + Score-Aware Contrastive Learning
- **Baselines**: Mean predictor, TF-IDF+Cosine, TF-IDF+SVR, FastText+Cosine, BiLSTM+Attention
- **Backbone study**: mBERT, XLM-R (proposed), mDeBERTa-v3, GTE — all dual-encoder + SCL
- **Ablations**: input format, preprocessing, topology, SCL weight, loss type, imbalance handling
- **XAI**: Gradient saliency + ERASER faithfulness (comprehensiveness/sufficiency)
- **Evaluation**: QWK (primary), bootstrap 95% CIs, paired bootstrap significance, MC Dropout uncertainty, selective prediction

## Quick Start

```bash
pip install -r requirements.txt --break-system-packages

# Step 1: Prepare data (run once)
python run_all.py --stage prepare

# Step 2: Classical baselines (CPU, ~10 min)
python run_all.py --stage baselines

# Step 3: BiLSTM neural baseline (CPU, ~10 min)
python run_all.py --stage bilstm

# Step 4: Transformer backbones (GPU required, ~3 hours on A40)
python run_all.py --stage transformers

# Step 5: Ablations on proposed model (GPU, ~2 hours)
python run_all.py --stage ablations

# Step 6: XAI analysis (after transformers)
python run_all.py --stage xai

# Step 7: Summary table
python run_all.py --stage summary

# Or run everything:
python run_all.py --stage all
```

## Local Experiment (no GPU, no HuggingFace needed)

```bash
python local_experiment.py
```

Runs Mean, TF-IDF+Cosine, TF-IDF+SVR, FastText+Cosine, BiLSTM on the full 1,184-sample dataset with bootstrap CIs, significance tests, per-subject breakdown, MC Dropout uncertainty, selective prediction, and gradient saliency XAI.

## XAI Visualization

```bash
python xai_visualizer.py
```

Generates PNG cards with highlighted Khmer text (per-character saliency), saliency bar charts, score/uncertainty panels. Output: `results/xai_visuals/`.

## Limitations

- **Hyperparameters are fixed defaults** across all transformer backbones (`lr=2e-5`,
  `dropout=0.2`, `freeze_layers` ratio-capped to leave at least 2 trainable encoder
  layers). No per-backbone hyperparameter search was performed; reported numbers
  should be interpreted as "out-of-the-box" performance.
- **BiLSTM is an architectural ablation**, not a vanilla baseline. It uses the same
  CORN + Score-Aware Contrastive Learning loss and dual-encoder + 4-way interaction
  topology as the proposed XLM-R model; only the encoder is swapped.
- **Classical baselines are similarity-based** (TF-IDF cosine, FastText cosine, mean
  predictor) and do not use class-balanced sampling. The only supervised classical
  baseline (TF-IDF + SVR) uses inverse-frequency sample weights for label balance.
- **Per-backbone tokenization differs** by design — each transformer uses its own
  native tokenizer (WordPiece for mBERT, SentencePiece-BPE for XLM-R / GTE,
  SentencePiece-BPE for mDeBERTa-v3). Tokenization is part of each pretrained model.
- **Sequence truncation.** Even at `max_seq_len=256`, ~25% of student answers exceed
  the model window (75th percentile of answer length is 383 characters). BiLSTM and
  all transformers operate on the truncated prefix.
