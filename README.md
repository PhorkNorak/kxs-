# KhmerXScore: Complete Experiment Suite

## Overview

This codebase implements the full experimental pipeline for the KhmerXScore framework:
- **KX-CL**: Dual-encoder XLM-RoBERTa with 4-way interaction + Score-Aware Contrastive Learning + CORN ordinal regression
- **5 Baselines**: Mean predictor, TF-IDF+Cosine, TF-IDF+SVR, FastText+Cosine, BiLSTM+Attention
- **4 Backbone study**: mBERT, XLM-R (proposed), PrahokBART, GTE — all with dual-encoder + SCL
- **3 LLM scorers**: GPT-4, Claude, Gemini — zero-shot
- **6 Ablation studies**: input format, preprocessing, topology, SCL, loss type, imbalance handling
- **XAI**: GradientSHAP + Integrated Gradients with ERASER faithfulness metrics
- **Evaluation**: QWK (primary), bootstrap 95% CIs, paired bootstrap significance tests, MC Dropout uncertainty, selective prediction analysis

## Input Format Experiment

Both input formats are tested across all models:
- `ar`: Student Answer + Reference Answer only
- `qar`: Question + Student Answer + Reference Answer (question-conditioned)

## Running Experiments

### Sequential (recommended for first run)

```bash
# Step 1: Prepare data (splits + preprocessing). Run ONCE.
python run_all.py --stage prepare

# Step 2: Run baselines (fast, ~5 min on CPU)
python run_all.py --stage baselines

# Step 3: Run transformer backbone study (4 backbones × 2 input formats × 5 seeds)
# This is the main experiment. ~40 runs total. Requires GPU.
python run_all.py --stage transformers

# Step 4: Run ablation studies on the proposed model
python run_all.py --stage ablations

# Step 5: Run LLM scoring (requires API keys, ~$20-50 in API costs)
python run_all.py --stage llms

# Step 6: Run XAI analysis (SHAP + IG + faithfulness)
python run_all.py --stage xai

# Step 7: Significance testing summary
python run_all.py --stage significance
```

### Run everything at once

```bash
python run_all.py --stage all
```

### CPU mode (for testing)

```bash
python run_all.py --stage baselines --device cpu
```

## Key References

- CORN: Shi, Cao & Raschka (2023). Pattern Analysis and Applications.
- SCL: Adapted from Zha et al. (2022) SupCR, NeurIPS.
- 4-way interaction: Conneau et al. (2017) InferSent; Reimers & Gurevych (2019) SBERT.
- ERASER: DeYoung et al. (2020). ACL.
- MC Dropout: Gal & Ghahramani (2016). ICML.
- Selective Prediction: Li et al. (2023). AIED.
- Bootstrap: Koehn (2004); Berg-Kirkpatrick et al. (2012).
- QWK threshold: Williamson et al. (2012).
- Class-balanced sampling: Cui et al. (2019). CVPR.
